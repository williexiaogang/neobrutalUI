### toggle
Base switch/toggle input. Required.

[Toggle docs](https://github.com/williexiaogang/neobrutalUI/tree/main/docs/components/api/toggle.md)

#### Class names
- component: `nb-toggle`

#### Syntax

```html
<!-- Basic toggle -->
<label class="nb-cluster">
  <input class="nb-toggle" type="checkbox" checked />
  <span>Airplane mode</span>
</label>
```

#### Rules
- Always include the base class `nb-toggle`.
- Modifiers are optional and can be combined when documented.
- Prefer native HTML states (disabled, checked, open) over custom state classes.
