### checkbox
Base checkbox class. Required.

[Checkbox docs](https://github.com/williexiaogang/neobrutalUI/tree/main/docs/components/api/checkbox.md)

#### Class names
- component: `nb-checkbox`

#### Syntax

```html
<label>
  <input class="nb-checkbox" type="checkbox" name="terms" />
  <span>I agree to the terms and conditions</span>
</label>
```

#### Rules
- Always include the base class `nb-checkbox`.
- Modifiers are optional and can be combined when documented.
- Prefer native HTML states (disabled, checked, open) over custom state classes.
