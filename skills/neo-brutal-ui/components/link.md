### link
Brutalist link style. Required.

[Link docs](https://github.com/williexiaogang/neobrutalUI/tree/main/docs/components/api/link.md)

#### Class names
- component: `nb-link`

#### Syntax

```html
<!-- Inline link -->
<p>
  Read the <a href="#" class="nb-link">documentation</a> for more details.
</p>

<!-- Standalone link -->
<a href="#" class="nb-link">Get Started</a>
```

#### Rules
- Always include the base class `nb-link`.
- Modifiers are optional and can be combined when documented.
- Prefer native HTML states (disabled, checked, open) over custom state classes.
